# Relógio Digital

Projeto front-end de um relógio digital desenvolvido para praticar manipulação de interface e atualização de conteúdo em tempo real.

## Sobre

Uma aplicação pequena e objetiva que apresenta horário digital no navegador. O projeto é um bom exemplo de microprojeto para demonstrar fundamentos de JavaScript e construção de interfaces simples.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Abra o arquivo principal HTML no navegador ou utilize Live Server.

## Objetivo

Exercício de fundamentos de desenvolvimento web, manipulação do DOM e atualização dinâmica de informações na interface.
